Connect an Android phone

This page talks to the phone directly over USB using the ADB protocol (via WebUSB), the same channel the old PC suites used — without installing anything on the phone.
  1. On the phone: Settings → About phone, tap Build number 7 times.
  2. Settings → System → Developer options → turn on USB debugging.
  3. Plug in the USB cable, click Connect phone, pick the device, then tap Allow on the phone.

No cable? On Android 11 and later, click Connect over Wi‑Fi, then scan the QR code in Developer options → Wireless debugging → Pair device with QR code. You only pair once; after that it connects with one click.

Needs Chrome or Edge on desktop. If you have Android SDK tools installed, run adb kill-server first — only one program can hold the USB connection.

Nearby devices

How it works: on your phone, turn on Receive in Droid Desk Companion, or install LocalSend (free, open source), on the same Wi‑Fi. Turn this on, then click Send files… (or drop files on a device) to send to the phone; phones can send to this computer too. No USB cable or developer options needed.
Methods: Same Wi‑Fi goes through your router and works with both apps. Direct link (Droid Desk Companion only) has this computer join a private Wi‑Fi from the phone for the transfer: one hop instead of two, so much faster on 2.4 GHz or busy networks, but this computer has no internet until it reconnects (automatically, right after). Auto picks Direct link only for big transfers on slow Wi‑Fi.
Everything is encrypted, nothing goes through the internet, and you're asked before any file is received. Droid Desk only listens on the network while this is on.
